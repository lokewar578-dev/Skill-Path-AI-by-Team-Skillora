# 🌟 Skill Path AI by Team Skillora

Skill Path AI is a next-generation, AI-driven Learning Management System (LMS) engineered to dynamically upskill learners through adaptive intelligence, interactive 3D environments, and highly personalized learning pathways.

## ✨ Core Features

### 🚀 3D Immersive Entrance
- A stunning, interactive 3D particle network greets users upon entry, symbolizing the interconnected nature of modern skills and data.

### 🧠 StatAI Copilot (Dynamic Document Analysis)
- Upload any statistical or technical document (PDF, DOCX) and instantly extract knowledge.
- The AI dynamically generates Custom Multiple Choice Questions (MCQs) strictly based on your uploaded document content.
- Generates 5, 10, or 20 dynamic questions seamlessly, supporting random extraction.

### 📊 Adaptive Skill Gap Analyzer
- Evaluates your pre-assessment and post-assessment performance.
- Visualizes precise competency domain growth (e.g., Data Science, NLP, Python) through dynamic Bar Graphs and Radar Charts.
- Immediately adjusts and suggests real-time course pathways based on identified skill gaps.

### 🌐 Multi-Language Support
- Full interface accessibility across 3 languages: **English, Hindi, and Telugu**.

### 🛠️ Interactive Admin Dashboard & Contact Support
- Specialized "Contact Admin" section for learners to directly submit queries, suggestions, and support tickets.
- Integrated tracking for Skill India and NPTEL pathway metrics.

## 💻 Tech Stack
- **Frontend Framework**: React (Vite)
- **Styling**: Tailwind CSS / Custom Glassmorphism CSS
- **Routing**: React Router DOM v6
- **Icons**: Lucide React
- **Document Parsing**: PDF.js, Mammoth.js

---

## 🚀 How to Run Locally

1. **Install Dependencies**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

2. **Start the Development Server**
   ```bash
   npm run dev
   ```
3. Open your browser and navigate to `http://localhost:5173`.

---

## ☁️ Deployment on Vercel (Zero Errors)

This project is fully configured for a flawless deployment on Vercel. 

1. Push this repository to your GitHub.
2. Go to [Vercel](https://vercel.com/new) and click **Import from GitHub**.
3. Under **Application Preset**, select **Vite**.
4. Click **Deploy**.

*(Note: A `vercel.json` file is included in this repository to prevent 404 routing errors upon page refresh).*
